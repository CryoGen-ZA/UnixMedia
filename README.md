# UnixMedia

A cross-platform (Windows / Linux / macOS) smart-TV-style launcher written in C# with Avalonia.
The home screen shows big tiles; activating a tile opens its URL in the OS default browser.

![Demo of the app](./RepoExtras/UnixMediaIntro.GIF)


## Run

```sh
dotnet run
```

Requires the .NET 10 SDK.

## Publish a standalone build

```sh
dotnet publish -c Release -r linux-x64   --self-contained
dotnet publish -c Release -r win-x64     --self-contained
dotnet publish -c Release -r osx-arm64   --self-contained
```

## Controls

The launcher starts fullscreen. The **⚙ Settings** button in the top bar opens a menu with:

- **Add tile**
- **Open websites fullscreen (kiosk)**: on by default
- **Sounds**: focus/select sounds, on by default
- **Intro animation**: the particle intro shown at startup, on by default
- **Power…**: Shut down, Restart or Exit to desktop

| Key                         | Action                                   |
|-----------------------------|------------------------------------------|
| Arrow keys                  | Move between tiles (Up from top row → Settings) |
| Enter / Space / click       | Open the tile's URL                      |
| S / Esc                     | Open the Settings menu                   |
| A / Insert                  | Add a tile                               |
| E, Menu key, right-click    | Edit tile                                |
| Delete                      | Remove tile                              |
| Ctrl + Left / Right         | Reorder tile                             |
| F11                         | Toggle fullscreen                        |

## Kiosk mode

With kiosk mode on, tiles open in the OS default browser in fullscreen kiosk mode, if it is
Firefox-based (Firefox, LibreWolf, Waterfox, Floorp) or Chromium-based (Chrome, Chromium, Edge,
Brave, Vivaldi). Other browsers, such as Safari, open in a normal window.

- The browser runs with its **own profile**, so it works even when your normal browser is open.
  Sign in to sites once inside it, and the logins are kept.
- Opening another tile replaces the browser currently on screen.
- Press **Escape** to close the browser and return to the UnixMedia home screen. Closing it any other
  way (Alt+F4, Cmd+Q) also returns you home.

While the kiosk browser is open, UnixMedia registers Escape as a system-wide hotkey, because the
browser has keyboard focus, not the launcher. It is released as soon as the browser closes:

| Platform        | Mechanism                                    | Notes |
|-----------------|----------------------------------------------|-------|
| Windows         | `RegisterHotKey`                             | |
| macOS           | Carbon `RegisterEventHotKey`                 | No Accessibility permission needed |
| Linux (X11)     | `XGrabKey` on the root window                | |
| Linux (Wayland) | XDG GlobalShortcuts portal (KDE, GNOME 48+, Hyprland) | The desktop asks you to confirm the shortcut the first time. It can be changed later in the desktop's shortcut settings. |

On Linux the app installs `~/.local/share/applications/io.github.UnixMedia.desktop` at startup.
The portals use it to identify the app, and it also adds UnixMedia to your application menu.

## Intro

At startup, particles swirl in to form the UnixMedia wordmark, then sweep away to reveal the home screen
(about 4 seconds), with an ambient pad, a chime and a soft swoosh. Press any key or click to skip it, or turn
it off under **⚙ Settings → Intro animation**. It is drawn in code with Skia, so it stays sharp at any
resolution and adds nothing to the download.

If it stutters, run with `UNIXMEDIA_DEBUG=1` to print the intro's frame rate, longest frame gap and whether
it is rendering on the GPU.

## Sounds

A soft tick plays when focus moves between tiles (keyboard/remote), and a chime plays when a tile is opened.
They are generated by the app. The intro has its own generated sound.
To use your own, drop `focus.wav`, `select.wav` and/or `intro.wav` into the `sounds/`
data folder below and restart. Playback uses the OS's built-in tools: winmm on Windows, `afplay` on macOS,
and `pw-play`, `paplay` or `aplay` on Linux.

## Data

Everything is stored under:

- Windows: `%APPDATA%\UnixMedia`
- Linux: `~/.config/UnixMedia`
- macOS: `~/Library/Application Support/UnixMedia`

| Path                 | Contents                              |
|----------------------|---------------------------------------|
| `tiles.json`         | Your tiles                            |
| `settings.json`      | Preferences (kiosk mode, sounds, intro) |
| `icons/`             | Copies of tile icon images            |
| `sounds/`            | Optional custom `focus.wav` / `select.wav` / `intro.wav` |
| `browser-profile/`   | Dedicated kiosk browser profile       |

Flatpak and Snap browsers can't reach that folder, so their kiosk profile is kept in
`~/.var/app/<app-id>/data/unixmedia-kiosk-profile` or `~/snap/<name>/common/unixmedia-kiosk-profile`.
